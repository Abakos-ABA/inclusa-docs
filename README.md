# Inclusa Accessibility Kit for Unreal Engine 5

Accessibility options your players expect, in one plugin, without a single binary asset:

| Feature | What the player gets | What you do |
|---|---|---|
| Subtitles | Size, background opacity, speaker names and colours, readable on bright scenes | Call **Show Subtitle** |
| Colour vision | Correction for protanopia, deuteranopia, tritanopia with strength slider | Nothing |
| Text and UI scale | Bigger text everywhere the kit draws, optional global UI scale | Use **Scaled Text** in your widgets |
| Key remapping | Rebind every player-mappable Enhanced Input key, conflict warnings, saved | Mark mappings as player-mappable |
| Settings menu | One ready-made, gamepad-friendly menu, live preview, saved on close | Call **Open Settings Menu** |
